# Data Science Day 02

A hands-on learning repository for practicing foundational data-science workflows in Python.

## Focus Areas

- Python data analysis
- NumPy fundamentals
- pandas workflows
- Data inspection and cleaning
- Exploratory analysis
- Data visualization

## Repository Purpose

This repository documents practical exercises while building the foundations needed for machine learning and AI engineering.

## Learning Workflow

```text
Load data → Inspect → Clean → Analyze → Visualize → Interpret
```

## Notes

Exercises are kept intentionally practical. As the project grows, notebooks and datasets should be organized by topic rather than by arbitrary lesson number.
